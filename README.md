# BPMN Project Assignments

Three business processes modelled in BPMN 2.0. Each assignment has its happy path, the failure paths with their resolutions drawn in the diagram, a Failure Path Register and a justification of the task types and gateways used.

## What each folder contains

| File | Contents |
|---|---|
| `README.md` | Overview, participants, embedded diagram, failure-path summary, justification summary, validation and limitations |
| `AssignmentN_BPMN_Diagram.bpmn` | The editable BPMN 2.0 model |
| `AssignmentN_BPMN_Diagram.png` | Diagram exported from the model |
| `AssignmentN_Failure_Path_Register.md` | Every failure: trigger, detection, BPMN construct, recovery, limit, outcome, diagram labels |
| `AssignmentN_Justification.md` | Why each task type, gateway and event was chosen |

## Viewing and editing

Open any `.bpmn` file in [Camunda Modeler](https://camunda.com/download/modeler/) with *File → Open File…*. The diagrams are wide; open the `.png` links above at full size and zoom in.
