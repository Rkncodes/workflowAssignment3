# BPMN Project Assignments

Three BPMN 2.0 process models. Each folder holds the editable model, one diagram export, the Failure Path Register, the task and gateway justification, and a README that summarises them.

| Assignment | Folder | Model | Diagram |
|---|---|---|---|
| 1 — Student Project Approval & Allocation System | [`BPMN_Assignment_1/`](BPMN_Assignment_1/) | [`.bpmn`](BPMN_Assignment_1/Assignment1_BPMN_Diagram.bpmn) | [`.png`](BPMN_Assignment_1/Assignment1_BPMN_Diagram.png) |
| 2 — Logistics & Shipment Exception Management | [`BPMN_Assignment_2/`](BPMN_Assignment_2/) | [`.bpmn`](BPMN_Assignment_2/Assignment2_BPMN_Diagram.bpmn) | [`.png`](BPMN_Assignment_2/Assignment2_BPMN_Diagram.png) |
| 3 — Loan Origination & Approval System | [`BPMN_Assignment_3/`](BPMN_Assignment_3/) | [`.bpmn`](BPMN_Assignment_3/Assignment3_BPMN_Diagram.bpmn) | [`.png`](BPMN_Assignment_3/Assignment3_BPMN_Diagram.png) |

The `.bpmn` files open in [Camunda Modeler](https://camunda.com/download/modeler/). Validation performed and known limitations are stated in each folder's README.
